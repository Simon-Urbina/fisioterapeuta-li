# automation/n8n/workflows/

Responsable: Valentina

Export en `.json` de cada flujo de n8n, uno por archivo, generado con
`scripts/exportar-n8n.sh` para que el trabajo hecho en la interfaz de n8n no
se quede solo en la máquina de quien lo hizo. Las credenciales nunca deben
quedar incluidas en estos exports.
